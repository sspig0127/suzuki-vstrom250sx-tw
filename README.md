# Suzuki V-Strom 250SX 台灣車主手冊

本 repo 收錄 Suzuki V-Strom 250SX（台灣版）相關的個人硬體、保養與使用參考資訊。

## 內容規劃

- 車輛規格與保養手冊
- 保養紀錄與里程追蹤
- 常見問題排除筆記
- 改裝與配件相關資訊

## 車輛基本規格（V-Strom 250SX 台灣版）

資料來源：[台鈴機車官網規格頁](https://www.suzukimotor.com.tw/product/v-strom-250sx/style_price.html#spec)（擷取時為 26 年式；引擎與車身核心規格 2023~2026 年式應維持相同，售價與配色請以官網當期公告為準）。

### 引擎

| 項目 | 規格 |
|---|---|
| 引擎型式 | 油冷單缸四行程 SOHC |
| 排氣量 | 249 c.c. |
| 缸徑 x 行程 | 76mm x 54.9mm |
| 壓縮比 | 10.7:1 |
| 最大馬力 | 26.5 PS / 9,000 rpm |
| 最大扭力 | 22.2 Nm / 7,300 rpm |
| 燃油系統 | 電子噴射 |
| 變速系統 | 國際 6 檔 |

### 懸吊與煞車

| 項目 | 規格 |
|---|---|
| 前懸吊 | 120mm 潛望式前叉 |
| 後懸吊 | 中置單槍，7 段預載可調 |
| 前煞車 | 單向雙活塞卡鉗＋310mm 碟盤＋ABS |
| 後煞車 | 單向單活塞卡鉗＋240mm 碟盤＋ABS |
| 前輪胎 | 100/90-19 M/C |
| 後輪胎 | 140/70-17 M/C |

### 車身尺寸與重量

| 項目 | 規格 |
|---|---|
| 車身尺寸（長×寬×高） | 2,180 x 880 x 1,355 mm |
| 軸距 | 1,440 mm |
| 最低離地高度 | 205 mm |
| 座位高度 | 835 mm |
| 裝備重量 | 167 kg |
| 油箱容量 | 12 L |

### 燃油效率（原廠測試值）

| 項目 | 數值 |
|---|---|
| 定速耗油量 | 54.43 km/L |
| 市區耗油量 | 30.32 km/L |
| 測試值 | 36.8 km/L |
| 能源效率等級 | 3 級 |

### 售價與配色（擷取時為 26 年式，僅供參考）

- 建議售價：NT$188,000（不含牌險）
- 配色：黑（YVB）、白（CN1）、黃（BT1）、藍（DB5）
